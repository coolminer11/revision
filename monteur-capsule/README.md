# Monteur de capsule

Outil gratuit pour monter une capsule vidéo : ta vidéo + ta présentation, synchronisées au clic, exportées directement dans le navigateur (rien n'est envoyé sur Internet).

Ouvrir `index.html` via un serveur (GitHub Pages par exemple). Les fichiers du dossier `js/` doivent rester à côté de `index.html`.

Navigateur conseillé : Chrome ou Edge récent sur ordinateur (export MP4). Les autres navigateurs exportent en WebM.
